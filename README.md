# Earth's Genesis Portal

hello! Acting as a website designer, could you build a website exploring the origins of Earth. It should have three categories including an interactive timeline, with pictures with zooming animations of every era with landscape imagery. The second category should be a simulator of any one of these eras where you can pull a toggle to see how you can build your own environments. The third should be about humans, focusing on our evolvement with animations of humans and comic strips. The website should have an immersive homepage and the loading screen should be an earth spinning.
